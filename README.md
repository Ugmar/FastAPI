# FastAPI AI Chat History Service

Компактный и эффективный веб-сервис на базе FastAPI, который предоставляет API для взаимодействия с языковой моделью Google Gemini и автоматически сохраняет историю запросов пользователей в базу данных с привязкой к их IP-адресу.

## 📝 Что делает проект

Сервис выступает в роли умного прослойного шлюза (Proxy) между клиентом и нейросетью Google Gemini, решая следующие задачи:

1. **Интеграция с ИИ (Google Gemini):** Принимает текстовые промпты от пользователя, отправляет их через официальный SDK в Gemini и возвращает сгенерированный нейросетью ответ.
2. **Логирование и история по IP:** Автоматически определяет IP-адрес клиента при каждом запросе. Промпт пользователя и ответ модели записываются в локальную базу данных.
3. **Просмотр личной истории:** Предоставляет эндпоинт для получения списка всех ранее отправленных запросов и ответов, сделанных с текущего IP-адреса.
4. **Автоматический менеджмент БД:** Самостоятельно инициализирует базу данных и создает необходимые таблицы при старте приложения (благодаря механизму `lifespan`).

## 🛠 Используемые технологии

Проект написан на современном стеке Python с акцентом на скорость разработки и простоту развертывания:

* **Python (>= 3.12):** Используются современные возможности языка и типизация.
* **FastAPI (>= 0.128.0):** Высокопроизводительный веб-фреймворк для создания REST API. Автоматически генерирует интерактивную документацию Swagger UI, доступную по адресу `/docs`.
* **Google GenAI SDK (google-genai >= 1.0):** Официальная библиотека от Google для интеграции с актуальными моделями Gemini (используется модель `gemini-2.5-flash`).
* **SQLAlchemy:** Мощная ORM-система для объектно-реляционного отображения. Позволяет работать с базой данных через структуры классов Python.
* **SQLite:** Легковесная встроенная база данных (все данные сохраняются локально в файл `data.db`), не требующая развертывания отдельного сервера БД.
* **Uvicorn:** Быстрый ASGI-сервер для запуска веб-приложения FastAPI.

```text

├── config.py       # Конфигурация приложения (хранение API-ключа Gemini)

└── pyproject.toml  # Метаданные проекта и управление зависимостями
